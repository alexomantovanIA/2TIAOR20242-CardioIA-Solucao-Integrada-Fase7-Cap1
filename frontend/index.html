Detalhes do CardioIA

Aderência FIAP (Fases 1-6)

  • Fase 1: Base de dados consolidada.
  • Fase 2: NLP e análise de risco inicial.
  • Fase 3: Monitoramento via IoT (Simulado).
  • Fase 4: Visão computacional para imagens.
  • Fase 5: Assistente conversacional Watson.
  • Fase 6: Predição multiagente avançada.

Escopo e Segurança

Este assistente utiliza modelos de Machine Learning para identificar padrões de risco cardíaco com base em dados clínicos e relatos.

  • Foco educacional e preventivo.
  • Triagem baseada em protocolos médicos.
  • Camada de segurança para sinais de urgência.
